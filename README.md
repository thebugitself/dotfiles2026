# dotfiles2026

Hyprland (Wayland) dotfiles for Arch Linux — dual monitor, waybar, rofi, kitty.

The repo is a reference of the full setup: which file controls what, every keybind, and
what has to change to use it on another machine. Grab any part of it.

Only configs that are actually in use are included. Leftovers and backups
(`.disabled`, `.save`, `.bak`, `.backup`, old wofi/foot/fuzzel configs) are left out.

## Contents

```
.config/
├── hypr/
│   ├── hyprland.lua        # entry config (monitor, env, autostart, animations, layout)
│   ├── keybinds.lua        # all keybinds
│   ├── rules.lua           # window rules + layer rules (blur, rofi animation)
│   ├── hyprlock.conf       # lock screen (clock, now-playing, playerctl controls)
│   ├── hyprpaper.conf      # leftover, wallpaper now handled by awww
│   └── scripts/
│       ├── cliphist-pick.sh   # clipboard history in rofi, with image thumbnails
│       ├── opacity.sh         # window opacity menu (rofi)
│       ├── now-playing.sh     # now-playing text for hyprlock/waybar
│       ├── password-cursor.sh # blinking cursor on hyprlock
│       └── togglefloat.sh     # leftover, not bound to anything
├── waybar/                 # top bar (workspaces + app icons, cpu/gpu/ram/temp, mpris)
├── rofi/                   # launcher (config.rasi + colors.rasi)
├── kitty/                  # terminal + search/scroll_mark kittens
├── wlogout/                # power menu (layout, style, icons)
├── quickshell/hyprquickpaper/  # wallpaper picker (Quickshell/QML) — SUPER+W
├── dunst/                  # notifications
├── fish/                   # shell (config, prompt, auto-start Hyprland on tty1)
├── gtk-3.0/, gtk-4.0/      # GTK theme
└── starship.toml           # starship prompt
extras/
└── burp-iconfont/          # Burp Suite icon font + codepoint remap script (see its README)
```

## Keybinds

| Bind | Action |
|---|---|
| `SUPER + Q` | terminal (kitty) |
| `SUPER + R` / `SUPER + D` | launcher (rofi) |
| `SUPER + E` | file manager (thunar) |
| `SUPER + B` | browser (firefox) |
| `SUPER + C` | close window |
| `SUPER + M` | exit Hyprland |
| `SUPER + V` | clipboard history (cliphist + rofi + image thumbnails) |
| `SUPER + W` | change wallpaper (quickshell hyprquickpaper) |
| `SUPER + O` | window opacity menu |
| `SUPER + H / J / K / L` | focus window (hjkl) |
| `SUPER + SHIFT + HJKL` | move window |
| `SUPER + CTRL + HJKL` | resize window |
| `SUPER + 1..9 / 0` | workspace 1..10 |
| `SUPER + SHIFT + 1..9 / 0` | move window to workspace |
| `SUPER + Space` | toggle float + center at 60% |
| `SUPER + P` | pin/unpin window — stays visible on every workspace (floats it first; pinning only works on floating windows) |
| `SUPER + Tab` | lock (hyprlock) |
| `SUPER + Escape` | power menu (wlogout) |
| `SUPER + SHIFT + W` | restart waybar |
| `Print` | screenshot region → swappy |
| `SUPER + Delete` / `Delete` | screenshot full / region to ~/Pictures |
| `XF86*` | volume (pamixer), brightness (brightnessctl), media (playerctl) |

## Requirements

```
hyprland waybar rofi kitty fish starship wlogout quickshell dunst awww hyprlock
cliphist wl-clipboard grim slurp swappy playerctl pamixer brightnessctl
thunar firefox jq ffmpeg
```

Font: **JetBrainsMono Nerd Font**. The Burp icon in waybar needs an extra font
(see `extras/burp-iconfont/`).

> Note: `kitty/kitty.conf` includes a theme generated by quickshell
> (`~/.local/state/quickshell/user/generated/terminal/kitty-theme.conf`). Without that
> quickshell setup, remove or comment out the `include` line.

## Install

```bash
git clone git@github.com:thebugitself/dotfiles2026.git
cd dotfiles2026
./install.sh            # backs up the old config to ~/.dotfiles-backup-<timestamp>, then copies
./install.sh --dry-run  # show what would be overwritten
```

`install.sh` copies `.config/*` to `~/.config/`, replaces `/home/len` with `$HOME`, and
optionally installs the Burp icon font. Afterwards **restart Hyprland** — the Lua config
does not fully reload without a restart.

## Notes

- The Hyprland config is **Lua** (`hyprland.lua` + `require("keybinds")` /
  `require("rules")`), not `hyprland.conf`.
- Layer transitions (rofi launcher + clipboard picker) are set in `rules.lua` via
  `layer_rule { animation = "popin 85%" }`, with durations in `hyprland.lua`
  (`layersIn`/`layersOut`).
- Clipboard images show as thumbnails in rofi (`rofi -show-icons` + `icon\x1f` escape),
  see `cliphist-pick.sh`.
- Pinning (`SUPER + P`) is floating-only — a Hyprland limitation, not a config choice.
  That is why the bind floats the window first.
